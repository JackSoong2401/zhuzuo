# 珠作 · 手串 DIY

手机端优先的手串工坊：点选珠子排出一串只属于你的手链。每颗珠子有独立价格，顺序、手围和报价会实时更新。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

## 可以做什么

- 点选珠盘把珠子穿上手串；选中已有珠子后再点，可替换或再加一颗
- 单指滑动旋转预览；按住珠子拖动可换位
- 按手围和贴合 / 适中 / 宽松余量计算成品内径
- 每颗珠子单独标价，底部实时小计，报价里列出明细和穿串工费
- 模板一键排满、自动补齐剩余圈口
- 撤销 / 重做，草稿保存在当前设备

珠子材质为工作室示意纹理，价格为演示用。
